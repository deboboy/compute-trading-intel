# Compute Trading Intel

Weekly intelligence on the emerging **compute-trading market** — the financialization of AI
compute into a tradable asset class (GPU futures & options, price indexes, and OTC spot
marketplaces). A Last Myle Engineering research product.

**Dashboard:** https://compute-trading-intel.vercel.app *(once deployed)*

## What it tracks

- **Derivatives layer:** CME × Silicon Data, Architect (AI Exchange), ICE, Nodal × Compute Desk —
  approvals, launches, contract specs, volumes.
- **Index layer:** Silicon Data, Ornn (OCPI), Compute Desk, SemiAnalysis — methodology changes,
  divergence between benchmarks.
- **Spot layer:** 20+ GPU capacity marketplaces (Vast.ai, VoltagePark, SF Compute, Hyperbolic,
  RunPod, Prime Intellect, Akash, etc.) — pricing moves, entrants, consolidation.
- **Regulatory:** CFTC review/comment cycles gating U.S. launches.
- **Capital:** funding rounds and private-credit GPU-collateral activity.

## Layout

```
briefs/
  summary.md          current executive summary (regenerated by cron)
  signals.json        signal cards: claim, source, url, confidence, run_date
  indexes.json        index/provider snapshot
  weekly/YYYY-MM-DD.md weekly digests
scripts/web_sync.py   briefs → web/public/compute-trading.json (honest-data policy)
web/                  Next.js dashboard (deployed on Vercel, root dir = web/)
```

## Data policy

The cron job rewrites `briefs/` each week; `scripts/web_sync.py` converts them verbatim into
`web/public/compute-trading.json`. Empty state is an empty list, never placeholder data.
Hand-editing `web/public/` is not allowed — regenerate instead.

Baseline research: `/root/evalbox-terminal-hermes/research/2026-10-19_compute-trading/brief.md`
(in the private evalbox workspace; the headline findings ship as the first summary).
